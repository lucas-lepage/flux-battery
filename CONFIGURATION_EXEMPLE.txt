À configurer uniquement dans Render > Environment :
NEO4J_URI = Connection URI du fichier Aura (commence par neo4j+s://)
NEO4J_USERNAME = neo4j
NEO4J_PASSWORD = mot de passe du fichier Aura
NEO4J_DATABASE = neo4j
MECHANIC_PASSWORD = mot de passe du mécanicien (12 caractères minimum)
OWNER_PASSWORD = mot de passe différent du responsable (12 caractères minimum)
RECYCLER_PASSWORD = mot de passe différent du recycleur (12 caractères minimum)
HOST = 0.0.0.0
COOKIE_SECURE = true

Ne pas ajouter le vrai fichier d'identifiants Aura à GitHub.
